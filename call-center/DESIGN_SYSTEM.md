# CallPilot — дизайн-система и настройки сайта

Файл фиксирует текущий формат CallPilot, чтобы не подбирать размеры, цвета, отступы и голоса заново.

Путь к основному CSS: `call-center/static/style.css`  
Путь к лендингу: `call-center/templates/landing.html`

---

## 1. Быстрый старт для нового сайта

1. Скопируйте блок CSS-переменных из раздела 2.
2. Задайте ширину контента через `--container` и отступы через `--page-pad`.
3. Используйте тёмный hero + светлый контент + бирюзовый акцент.
4. Заголовки — по шкале из раздела 3, основной текст карточек — **17 px, тёмный**.
5. В шапке — только одна главная кнопка. Второстепенные ссылки — в навигацию.
6. Не наклоняйте карточки, не дублируйте метрики в соседних полосах.
7. Для демо-звонков используйте только нативные русские голоса edge-tts.

## 5. Структура лендинга

Порядок секций:

1. **Header** — логотип, навигация, одна главная CTA.
2. **Hero** — заголовок, лид, две CTA, trust-строка, карточка звонка.
3. **Hero metrics** — 4 показателя внутри тёмного блока.
4. **Было / Стало** — сырой транскрипт vs готовая карточка.
5. **Как это работает** — 4 шага + mid-CTA.
6. **Почему выгодно** — 3 карточки.
7. **Что видит менеджер** — 3 карточки.
8. **Для кого** — 4 карточки.
9. **Пилот** — тёмный блок с условиями и CTA.
10. **Footer** — бренд, кнопки, контакт.

### Чего не делать

- Не добавлять отдельную светлую полосу метрик сразу под hero: она дублирует тёмную.
- Не делать две конкурирующие кнопки в шапке: главная — одна.
- Не наклонять hero-карточку.
- Не перегружать hero-карточку бейджами, статусами и плашками.
- Не дублировать один кейс с разными QA-score в разных блоках.
- Не использовать эмодзи для иконок; только монохромные SVG/символы.

## 7. Hero

### Текст

- Eyebrow: `CallPilot · AI-контроль качества звонков`.
- H1: `100% звонков под контролем. Менеджер смотрит только исключения.`
- Лид: расшифровка, карточка в CRM, QA-чек-лист, человеку — только нарушения.
- CTA: primary «Открыть демо», secondary «Смотреть оффер».
- Trust-строка: `пилот 100–300 звонков`, `2 недели до первых цифр`, `без замены операторов`.

### Карточка звонка

Только ключевые элементы:

- тонкий topbar: точки + «Карточка звонка»;
- eyebrow: «Звонок #1042 · возврат»;
- заголовок: «Клиент требует возврат сегодня»;
- QA-score: **0 QA**, красный круг;
- аудиоплеер;
- нарушение: `critical` + «Ложное обещание возврата» + цитата.

Запрещено добавлять в hero-карточку:

- `100% QA`, «только исключения», «ручная проверка»;
- `auto-pass не пройден`, «Открыть звонок»;
- дополнительные плашки и статусы.

Карточка **не наклоняется** (`transform: none`), ширина 100%, radius 22 px, тень `0 40px 90px rgba(0,0,0,.35)`.

### QA-score кейса

Для кейса «ложное обещание возврата» использовать **0 / 100** во всех блоках:

- hero: `0 QA`;
- «Было / Стало»: `0 / 100`.

## 14. Голоса и аудио

Демо-аудио и озвучка видео — **только нативные русские голоса edge-tts**:

| Роль | Голос |
|---|---|
| Оператор | `ru-RU-DmitryNeural` |
| Клиент | `ru-RU-SvetlanaNeural` |
| Диктор видео | `ru-RU-SvetlanaNeural`, rate `-2%` |

Параметры аудио:

- MP3, 24 kHz, mono, 48 kbps;
- пауза между репликами диалога 350 ms;
- манифест таймкодов: `call-center/data/audio_manifest.json`;
- кэш TTS: `call-center/.cache/tts/`;
- при сбое голоса — fallback на `ru-RU-SvetlanaNeural`, не на английский TTS.

### Паузы на знаках препинания в нарации

- запятая — 140 ms;
- тире — 220 ms;
- двоеточие / точка с запятой — 280 ms;
- точка — 360 ms;
- восклицание / вопрос — 420 ms;
- многоточие — 500 ms;
- между сценами видео — 450 ms.

Текст нарации режется на фразы по знакам препинания, каждая фраза синтезируется отдельно, затем фрагменты склеиваются с паузами. Это даёт русскую интонацию, а не «проглатывание» запятых.

Не использовать AITUNNEL `nova`/`onyx` для русского демо: слышен английский акцент.

## 17. Тон текста

- Русский деловой язык, без кальки с английского.
- «Решение всегда принимает человек: ИИ готовит черновик, менеджер только подтверждает».
- Не использовать «человек остаётся в контуре» — звучит как перевод.
- Термины `auto-pass` и `manual_review` объяснять по-русски: «авто-проверка» и «ручная проверка».
- В одном кейсе — один QA-score во всех блоках.
- Пилот: 100–300 звонков, 2 недели, без замены операторов.

# Результаты live-прогона

Статус: ожидает реального ключа AITUNNEL.

## Как заполнить

1. Вставьте AITUNNEL_API_KEY в .env.
2. Проверьте ключ:

```powershell
.venv\Scripts\python.exe -m scripts.smoke_llm
```

3. Запустите 30 кейсов:

```powershell
.venv\Scripts\python.exe -m app.cli batch --strict
```

4. Сгенерируйте экономику:

```powershell
.venv\Scripts\python.exe -m scripts.economics
```

5. Перенесите цифры из data/test_run.json и docs/economics.txt в этот файл и в docs/REPORT.md.

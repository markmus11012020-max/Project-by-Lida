# Задание: карточка Call-Pilot на aillix.ru

## Цель

Добавить на сайт группы Aillix отдельную карточку продукта **Call-Pilot** и привести трафик на демо и лендинг `call-pilot.ru`.

Карточка должна:

- показать Call-Pilot как продукт группы Aillix;
- объяснить связку **AI заполняет карточку → оператор подтверждает → CRM получает результат → QA проверяет 100% звонков**;
- вести на демо `call-pilot.ru/dashboard`;
- не дублировать весь лендинг Call-Pilot и не конкурировать с ним в поиске.

## Где разместить

Рекомендуемый вариант: новый блок **«Продукты»** на `aillix.ru` после блока «Услуги».

Альтернатива: отдельная карточка в разделе «Кейсы», если новый раздел не нужен.

Не размещать карточку внутри списка обычных услуг: Call-Pilot — продукт, а не часовая консультация.

### Метрики на карточке

Использовать только проверяемые цифры:

```text
100% звонков проходят разбор
10 критериев QA
0 карточек в CRM без подтверждения
2 недели до пилота
```

Не писать «−40%» как факт, если это цель, а не измеренный результат. Можно подписать: «цель пилота — −40% ручной постобработки».

## Визуал

Использовать один из файлов:

```text
call-center/screenshots/dashboard.png
call-center/screenshots/landing_hero.png
```

Рекомендация:

- для широкой карточки — `dashboard.png`, 16:10;
- для hero-карточки продукта — `landing_hero.png`, 16:9;
- не использовать `landing.png` целиком: страница слишком длинная для карточки.

На изображении не должно быть реальных персональных данных. Демо-данные синтетические.

## Дизайн

- Стиль Aillix: тёмный технологичный фон, акцент Aillix, крупная типографика.
- Карточка должна выглядеть как продукт, а не как баннер.
- Внутри карточки: бейдж, заголовок, подзаголовок, 2–3 строки описания, теги, метрики, CTA.
- Hover: лёгкий подъём и подсветка границы.
- На мобильном: одна колонка, кнопки на всю ширину.
- Не использовать стоковые фото и фейковые логотипы клиентов.

## SEO

- Карточка не должна копировать лендинг Call-Pilot.
- Заголовок карточки: `Call-Pilot — AI-карточка в CRM и 100% QA звонков`.
- Ссылка на `call-pilot.ru` — обычная ссылка, без `nofollow`.
- `rel="noopener"` для внешних переходов.
- Не делать canonical на Aillix: canonical должен остаться на `call-pilot.ru` у самого продукта.
- В описании карточки использовать 1–2 ключевых запроса: «контроль качества звонков», «AI-карточка в CRM».

## Аналитика

События:

```text
aillix_callpilot_card_view
aillix_callpilot_demo_click
aillix_callpilot_lead_click
aillix_callpilot_landing_click
```

UTM уже указаны в ссылках. Не менять `utm_source=aillix`.

## Обратная ссылка

На Call-Pilot в футере уже есть:

```text
Группа Aillix · aillix.ru
```

Проверить, что ссылка ведёт на `https://aillix.ru/` и открывается корректно.

## Что не делать

- Не писать `CallPilot` без дефиса в пользовательских текстах.
- Не обещать «полное соответствие 152-ФЗ» без юридической проверки.
- Не публиковать фейковые отзывы, логотипы клиентов и цифры.
- Не делать карточку отдельным лендингом с полным дублем Call-Pilot.
- Не вести на старую версию демо или на `callpilot.*`.

## Критерии приёмки

- [ ] На aillix.ru есть отдельная карточка Call-Pilot.
- [ ] В карточке есть HITL-формулировка.
- [ ] Есть ссылка на демо и на пилот.
- [ ] UTM-метки проставлены.
- [ ] Бренд написан `Call-Pilot`.
- [ ] На мобильном карточка не ломается.
- [ ] Нет реальных персональных данных на скриншоте.
- [ ] Ссылка на демо открывается и ведёт на `call-pilot.ru/dashboard`.
- [ ] Обратная ссылка с Call-Pilot на Aillix работает.

## Ориентир по срокам

- Карточка и тексты: 2–3 часа.
- Вёрстка и адаптив: 3–4 часа.
- Аналитика и проверка ссылок: 1 час.
- Итого: 1 рабочий день.

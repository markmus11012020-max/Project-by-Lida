# Задание: карточка Call-Pilot на aillix.ru

## Цель

Добавить на сайт группы Aillix отдельную карточку продукта **Call-Pilot** и привести трафик на демо и лендинг `call-pilot.ru`.

Карточка должна:

- показать Call-Pilot как продукт группы Aillix;
- объяснить связку **AI заполняет карточку → оператор подтверждает → CRM получает результат → QA проверяет 100% звонков**;
- вести на демо `call-pilot.ru/dashboard`;
- не дублировать весь лендинг Call-Pilot и не конкурировать с ним в поиске.

## Где разместить

Рекомендуемый вариант: новый блок **«Продукты»** на `aillix.ru` после блока «Услуги».

Альтернатива: отдельная карточка в разделе «Кейсы», если новый раздел не нужен.

Не размещать карточку внутри списка обычных услуг: Call-Pilot — продукт, а не часовая консультация.

## Дизайн

- Стиль Aillix: тёмный технологичный фон, акцент Aillix, крупная типографика.
- Карточка должна выглядеть как продукт, а не как баннер.
- Внутри карточки: бейдж, заголовок, подзаголовок, 2–3 строки описания, теги, метрики, CTA.
- Hover: лёгкий подъём и подсветка границы.
- На мобильном: одна колонка, кнопки на всю ширину.
- Не использовать стоковые фото и фейковые логотипы клиентов.

## SEO

- Карточка не должна копировать лендинг Call-Pilot.
- Заголовок карточки: `Call-Pilot — AI-карточка в CRM и 100% QA звонков`.
- Ссылка на `call-pilot.ru` — обычная ссылка, без `nofollow`.
- `rel="noopener"` для внешних переходов.
- Не делать canonical на Aillix: canonical должен остаться на `call-pilot.ru` у самого продукта.
- В описании карточки использовать 1–2 ключевых запроса: «контроль качества звонков», «AI-карточка в CRM».

# Приложение: услуга «Сайты и запуск» для Aillix

Это отдельная услуга Aillix, **не тариф Call-Pilot**. Не смешивать её с карточкой продукта.

## Где разместить

В разделе «Услуги» Aillix добавить блок:

```text
Сайты и запуск
```

Подзаголовок:

```text
Соберём сайт, демо или лендинг и подберём хостинг под задачу — от статики до VPS.
```

## Три варианта

### 1. Статический лендинг

```text
Хостинг: 0 ₽/мес
```

Подходит:

- обычный HTML/CSS/JS;
- лендинг без бэкенда;
- витрина продукта.

Площадки:

- GitHub Pages;
- Cloudflare Pages;
- Vercel.

Что делает Aillix:

- собирает статическую версию;
- подключает домен и HTTPS;
- настраивает форму через внешний сервис/Telegram.

Ограничение: нет Python/FastAPI и серверной логики.

### 2. Сайт на shared-хостинге

```text
Хостинг: 150–300 ₽/мес
```

Подходит:

- WordPress;
- PHP-сайт;
- простая форма обратной связи;
- сайт без сложного бэкенда.

Плюс: не нужно администрировать Linux.
Минус: Python/FastAPI и очереди сюда не поставить.

### 3. VPS для демо

```text
Хостинг: 200–400 ₽/мес
1 CPU / 1 ГБ RAM / 10–15 ГБ NVMe
```

Подходит:

- небольшое интерактивное демо;
- FastAPI + SQLite + Caddy;
- низкий трафик;
- без Postgres, worker и scheduler.

Для Call-Pilot в текущем виде лучше **2 ГБ RAM**, но демо без очереди может жить и на 1 ГБ. Для пилота с Postgres/worker — 4–8 ГБ.

## Что писать в услуге

```text
Подберём хостинг под задачу:
— статический лендинг — бесплатно;
— WordPress/PHP — shared-хостинг;
— интерактивное демо — VPS.

Развернём, подключим домен, HTTPS, аналитику и форму заявки.
```

Важно: 0/150/300/400 ₽ — это **стоимость хостинга у провайдера**, а не стоимость работы Aillix. Работы по сборке, переносу и настройке считаются отдельно.

## Что не делать

- Не продавать shared-хостинг как площадку для Call-Pilot: там нет Python/FastAPI.
- Не обещать «бесплатный хостинг» для динамического демо с БД и очередью.
- Не смешивать тарифы хостинга с тарифами Call-Pilot.
- Не публиковать цены провайдеров как фиксированные навсегда: они меняются.

# Демо Call-Pilot на 2–3 минуты

## Подготовка

1. В `.env` указан `AITUNNEL_API_KEY`.
2. Установлены зависимости.
3. Запущен Call-Pilot:

```powershell
cd call-center
..\.venv\Scripts\python.exe -m uvicorn call_center_app:app --host 127.0.0.1 --port 8020
```

4. Открыты вкладки:

- http://127.0.0.1:8020/
- http://127.0.0.1:8020/dashboard
- http://127.0.0.1:8020/calls/call_02
- http://127.0.0.1:8020/qa
- http://127.0.0.1:8020/audit

## 0:00–0:20. Проблема

Покажите лендинг: QA слушает 2–5% звонков, оператор тратит минуты
на карточку, жалобы всплывают постфактум. Call-Pilot проверяет 100%
звонков, AI готовит карточку, оператор подтверждает.

## 0:20–0:40. Dashboard

Покажите `/dashboard`: 6 синтетических звонков, KPI, очередь ручной
проверки, `need_review`, приоритеты и SLA.

## 0:40–1:10. Карточка звонка

Откройте `/calls/call_02`: аудио, транскрипт с таймкодами, карточка,
QA-чек-лист. Покажите critical-находки: ложное обещание возврата.

## 1:10–1:35. QA и HITL

Покажите, что AI не пишет в CRM сам. Оператор проверяет поля,
исправляет и подтверждает. После подтверждения финальная версия
уходит в CRM, а правки видны в аудите.

## 1:35–2:00. QA-аналитика

Откройте `/qa`: покрытие QA, auto-pass, ручные проверки, топ нарушений,
средний score. Покажите, что менеджер видит только исключения.

## 2:00–2:20. Экономика

На лендинге откройте блок ROI: 1000 звонков в месяц, 3 минуты
на карточку, 215 ₽/час. Экономия 8 600 ₽/мес, 8,6 ₽ на звонок.

## 2:20–2:25. Аудит и API

Откройте `/audit`: действия, вход, выход, статус, ошибка, duration_ms.
Коротко скажите, что те же данные доступны через API и экспорт CSV/JSONL.
